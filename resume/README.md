# RESUME

---

## 概要

本リポジトリには、高木勇輝 / Yuki Takagi の職務経歴書、PDF、職務経歴に関連するポートフォリオ補足資料、図式化資料、分析手順・評価設計に関する補足資料を配置しています。

内容は、実務経験および個人AI R&Dをもとに、AI Governance、Auditability、AI Risk Management、LLM Evaluation、  
仕様設計 / ドキュメント設計などの職務上説明可能な能力カテゴリへ整理したものです。

主な関連領域は、AI Governance、Responsible AI、AI Safety、Auditability、AI Risk Management、LLM Evaluation Design、Runtime Governance、Traceability、Specification Design、Documentation Design です。

現時点では非公開の個人R&Dについては、固有名や詳細構成を出さず、能力カテゴリとして抽象化しています。

## English Summary

This repository contains resume materials, PDF versions, portfolio-related supplementary materials, diagrams, and supplementary notes on the analysis procedure and evaluation design used in preparing the resume.

The resume files are maintained in Markdown, and the PDF versions are laid out using VSCode Markdown PDF and CSS.

The materials are based on my practical work experience and personal AI R&D. They are organized into professionally explainable capability categories such as AI Governance, Auditability, AI Risk Management, LLM Evaluation, specification design, and documentation design.

The main related areas include AI Governance, Responsible AI, AI Safety, Auditability, AI Risk Management, LLM Evaluation Design, Runtime Governance, Traceability, Specification Design, and Documentation Design.

Currently non-public personal R&D and individual systems are not disclosed by their names or detailed internal structures. Instead, they are abstracted into capability categories and work-relevant design areas.

If the diagrams or text embedded in images are difficult to read in the PDF files, please zoom in on the PDF, refer to the Markdown resume files, or view the image files under `assets/images/`.

In the Markdown resume files and clickable PDF versions, each embedded image links to the corresponding image file on GitHub.

Viewing and internal sharing for recruitment, screening, interview, and evaluation purposes are permitted. Unauthorized reproduction, redistribution, modification, commercial use unrelated to recruitment or evaluation, use as training data, or other secondary use is prohibited.

For details, see [TERMS_OF_USE.md](./TERMS_OF_USE.md).
